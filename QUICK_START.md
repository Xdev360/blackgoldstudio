```html

```

### 3️⃣ **Update Social Links** (< 2 minutes)

- Snapchat link

- Your shop URL

### 4️⃣ **Replace Logo** (< 1 minute)

```html

```

Test on your phone and you're ready to share!

## 🔧 Basic Customization

### Change Colors
Open `styles.css` and find these hex codes:
```css
#D4A5D4  /* Primary purple */
#F8C4E6  /* Secondary pink */
#8B5A8B  /* Dark purple accent */
```
Replace with your brand colors using Find & Replace (Cmd+H / Ctrl+H)

### Change Fonts
Google Fonts are already imported. To change:
1. Go to [Google Fonts](https://fonts.google.com)
2. Select fonts you like
3. Copy the import link
4. Paste in index.html line ~22

### Change Button Text
All button descriptions are clearly marked in `index.html`:
```html
<span class="button-label">Your Text Here</span>
```
